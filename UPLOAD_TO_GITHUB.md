# Safest GitHub publishing steps

The final dissertation points to:

`https://github.com/DLKramer1998/MLDS_Demi_Kramer_Imperial`

To preserve that exact URL while replacing the old analysis with this clean final repository:

1. Open the existing `MLDS_Demi_Kramer_Imperial` repository on GitHub.
2. Go to **Settings -> General -> Repository name**.
3. Rename it to `MLDS_Demi_Kramer_Imperial_archive` (or another archive name).
4. Create a **new public repository** named exactly `MLDS_Demi_Kramer_Imperial`.
5. Do not initialise it with a README, `.gitignore`, or licence because those files are already supplied here.
6. Upload the contents of this folder to the new repository and commit them.
7. Open `https://github.com/DLKramer1998/MLDS_Demi_Kramer_Imperial` in a private/incognito window and confirm the README, four notebooks, three Stan files, and `data/` folder are visible.

This leaves the URL printed in the dissertation pointing at the clean final repository while preserving the previous repository under an archive name.
