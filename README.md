# Data files

This directory contains the exact CSV files referenced by `chapter2_applied.ipynb`:

- `diabetes_binary_health_indicators_BRFSS2015.csv`
- `UCI_Credit_Card.csv`

The first is derived from the 2015 CDC Behavioral Risk Factor Surveillance System diabetes health-indicators extract. The second is the UCI Default of Credit Card Clients dataset described by Yeh and Lien (2009).
